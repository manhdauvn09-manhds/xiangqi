## Migration Path

### For Development:
```bash
cd xiangqi
npm install
npm run dev              # Dev server at https://localhost:5173
                        # Hot reload enabled, proxies to API at :8787
npm run lint:js         # ESLint check
npm run build           # Production build → dist/
```

### For Production:
```bash
# Build new container
docker build -f Dockerfile.phase1 -t xiangqi:phase1 .

# Or use MCP deploy tool
mcp deploy { server_id: "mcp-80", app_id: "xiangqi-frontend" }
mcp deploy { server_id: "mcp-80", app_id: "xiangqi-api" }
```
