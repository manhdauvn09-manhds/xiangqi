👥 User Management

User List & Search

Access the complete user database:

/admin/users

Available Filters:

  • Status: Active, Suspended, Banned, Inactive
  • ELO Range: Min-Max rating
  • Join Date: From-To date
  • Last Activity: Last login date
  • Verification: Email verified, Phone verified

User Actions

View User Profile

Click on username to view:

  • Account information (email, join date, 2FA status)
  • ELO ratings (Standard & Blind)
  • Game history and statistics
  • Account flags and notes
  • Login history and activity timeline

Modify User Account

Admin can:

  • Reset password: User must change on next login
  • Change email: Update email address
  • Edit display name: Modify username
  • Adjust ELO: Manually modify rating (use carefully!)
  • Reset 2FA: Re-enable if user loses access

Suspend/Ban Users

⚠️ Account Suspension

Suspend: Temporary restriction (auto-unlock after period)

POST /admin/users/{id}/suspend
{
  "reason": "Cheating suspected",
  "duration_days": 30,
  "notify_user": true
}

Ban: Permanent restriction (requires manual unlock)

POST /admin/users/{id}/ban
{
  "reason": "Multiple violations of ToS",
  "notify_user": true,
  "refund": false
}

🎮 Game Control

Active Games Monitoring

Monitor all ongoing games in real-time:

/admin/games/active

Game Controls:

  • Force end: Terminate game (both players notified)
  • Pause/Resume: Temporarily stop game timer
  • Reset: Return to starting position
  • Award win: Manually assign victory
  • Declare draw: Force game as draw

ELO Management

Adjust Player Rating

Use sparingly! Only for corrections or special cases.

PATCH /admin/users/{id}/elo
{
  "variant": "standard",
  "new_rating": 1800,
  "reason": "Rating error correction",
  "log_reason": true
}

Reset Seasonal Ratings

Reset all ratings at season end:

POST /admin/elo/reset-season
{
  "season": "2026-Q2",
  "preserve_percentile": true
}

🔌 Admin API Reference

Authentication

All API requests require Bearer token in Authorization header:

Authorization: Bearer {JWT_TOKEN}

Core Endpoints

GET /admin/api/users

List all users with filters

Query params: limit, offset, status, elo_min, elo_max, sort

GET /admin/api/users/{id}

Get user details

PUT /admin/api/users/{id}

Update user information

{
  "email": "new@email.com",
  "display_name": "New Name",
  "status": "active"
}
POST /admin/api/users/{id}/reset-password

Reset user password (temporary)

POST /admin/api/users/{id}/suspend

Suspend user account

{
  "reason": "Violation reason",
  "duration_days": 30
}
DELETE /admin/api/users/{id}

Permanently delete user account

⚠️ WARNING: Irreversible action

GET /admin/api/games

List games with filters

Query params: limit, offset, status (active, completed), date_from, date_to

POST /admin/api/games/{id}/end

Forcefully end a game

{ "reason": "Admin termination" }
GET /admin/api/health

Check system health

Response: JSON with component statuses

GET /admin/api/analytics

Get analytics metrics

Query params: date_from, date_to, metric (dau, games, errors)

Error Handling

HTTP/1.1 400 Bad Request
{
  "error": "validation_error",
  "message": "Email already exists",
  "details": { "email": "Invalid email format" }
}
HTTP/1.1 401 Unauthorized
{
  "error": "auth_failed",
  "message": "Invalid token or expired"
}
HTTP/1.1 403 Forbidden
{
  "error": "permission_denied",
  "message": "Insufficient privileges for this action"
}

🔒 Security Guidelines

Critical Security Practices

  • ✅ Use strong passwords: 16+ chars, mixed case, numbers, symbols
  • ✅ Enable 2FA: TOTP (Google Authenticator) or SMS
  • ✅ VPN only: Access admin panel only through VPN
  • ✅ Session timeout: Auto-logout after 15 minutes of inactivity
  • ✅ Audit everything: All admin actions logged
  • ✅ Rotate credentials: Every 90 days minimum
  • ✅ Monthly reviews: Audit logs for suspicious activity
  • ✅ Incident response: Have a plan for breaches

Activity Logging

All administrative actions are logged:

/admin/audit-log
Field Description
Timestamp When action occurred (UTC)
Admin Which admin performed action
Action Type of action (create, update, delete, suspend, etc.)
Resource What was modified (user ID, game ID, etc.)
Changes Before/After values
IP Address Admin's IP address
Status Success/Failure

Data Protection

  • Encryption: All data encrypted at rest (AES-256)
  • TLS: All communications encrypted in transit (TLS 1.3)
  • Backups: Daily encrypted backups, 30-day retention
  • Compliance: GDPR-compliant data handling

Incident Response

If you suspect a breach:

  1. Immediately change your admin password
  2. Enable 2FA if not already enabled
  3. Review audit logs for suspicious activities
  4. Check for unauthorized admin accounts
  5. Notify other admins
  6. Contact security team: security@xiangqi.games-core.com
  7. Force password reset for all users if necessary

🔧 Troubleshooting

Q: Can't login to admin panel?

A: Check:

  • Email and password are correct
  • 2FA code is current (within 30 seconds)
  • Your IP is whitelisted (contact admin)
  • Account status is active (not suspended)
  • Browser cookies enabled

Q: Admin action failed?

A: Check:

  • Insufficient permissions (check role)
  • Resource doesn't exist (user/game already deleted)
  • Invalid data format (review API schema)
  • Server error (check system health)
  • Rate limited (wait before retrying)

Q: System running slowly?

A: Check:

  • Server CPU/Memory usage
  • Database query performance
  • Number of active games
  • Recent backups running
  • Network connectivity

Q: Need to reset user 2FA?

A: Steps:

  1. Go to user profile in admin panel
  2. Click "Security Settings"
  3. Click "Reset 2FA"
  4. User will need to re-setup 2FA on next login

Q: How to export user data for analysis?

A: Use:

GET /admin/api/users?limit=10000&format=csv

Or use the Export button in Users dashboard
