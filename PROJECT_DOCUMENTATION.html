📐 Architecture Overview ▼

System Architecture

Cờ Tướng Vương là một nền tảng chơi cờ tướng (Xiangqi) với chế độ Puzzle hàng ngày, tính năng Bot AI nhiều cấp độ, và hệ thống Leaderboard ELO.

Request Flow

User Browser → HTML/JS (ES Modules)
Frontend → Hash Router (#/daily, #/play, etc.)
Game Controller → Board logic + Move validation
Backend API → FastAPI (REST + WebSocket)
Database → SQLite (games, users, elo)
Authentication → JWT + Google OAuth

Key Subsystems

🎯 Daily Puzzle Mode

Xiangqi Daily: 14 thực cấp độ ≥3 nước
Chess Daily: 310 puzzle × 100 level

🤖 AI Engine

Xiangqi AI: Negamax + History Heuristic (L1-10)
Chess AI: chess-mini.js eval

🔐 Security

JWT + OAuth, Rate limiting, Anticheat memory management, Login failure tracking

🌐 Networking

WebSocket for real-time game sync, REST API for data, Google Sign-In integration

🔒 Security Considerations & Best Practices ▼

Key Security Features (Phase 7)

  • JWT Secret: Rotated quarterly. Production requires env var (sys.exit if missing)
  • Password Hashing: bcrypt with salt rounds configurable
  • Rate Limiting: Per IP per endpoint, customizable per route
  • Anticheat: Win-rate anomaly detection (>70% win rate with short moves)
  • Move Validation: Server-side validation via xiangqi_engine.py
  • SQL Injection Prevention: Whitelist-based column filtering (_PATCH_ME_ALLOWED_COLS)
  • CORS: Restricted origins (no wildcard with credentials=True)
  • HTTPS Only: Cloudflare SSL mode = Full
  • CSP Headers: Prevent XSS, clickjacking

Vulnerability Mitigation
SQL Injection Whitelist column names, parameterized queries
XSS (Cross-Site Scripting) CSP headers, input sanitization, no eval()
CSRF (Cross-Site Request Forgery) CORS restrictions, no wildcard origins
Brute Force Login failure tracker (5 failures → 15min lock)

DDoS Cloudflare protection, rate limiting

FEN Validation

All FEN strings must have exactly 8 ranks (Western chess = 8x8 board)

// Valid FEN: 8 ranks separated by '/'
"rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1"
              ↑       ↑       ↑       ↑       ↑       ↑       ↑       ↑
             rank8  rank7  rank6  rank5  rank4  rank3  rank2  rank1

Error Handling

Key files:

  • chess/chess-mini.js - FEN parser with validation
    • Checks for null/undefined FEN
    • Validates 8 rank count
    • Detailed error messages for debugging
  • ui/daily-chess-page.js - Render with error recovery
    • Try-catch around FEN parsing
    • Displays error to user instead of crashing
    • Includes puzzle ID and FEN in error output
